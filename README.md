# Rook

Rook is a mobile-first house-hunting workspace for discovering, comparing, visiting, and following up on rentals and homes.

## Initial goals
- One shared property model for apartments, townhomes, houses, and homes for sale
- Map-first browsing with Google Maps integration
- Shortlist and visit notes
- Showing / information-request tracking
- Email follow-up status
- Reuse shared search, parsing, status, and follow-up logic rather than bespoke per-view behavior

This repository is the initial Rook scaffold.
